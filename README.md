# Chinola · vista previa nativa (SwiftUI)

Solo la **interfaz** de la versión nativa de Chinola, con datos de ejemplo, para
validar pantallas en el simulador de iOS mediante GitHub Actions. **No** contiene
backend, claves, sincronización ni lógica de negocio — todo eso vive en el
repositorio privado de la app.
